# tychoniana-preview — retired

This repository served the unlisted preview of the Tychoniana portal. The site
went public at <https://tychoniana.com/> and the preview was retired on
2026-09-16: every address under `https://chrisivarwester.github.io/tychoniana-preview/`
now redirects to the same path on tychoniana.com (`404.html` carries the
path-preserving redirect; `index.html` covers the root).

Do not republish content here — `docs/tychoniana/_publish_preview.ps1` in the
organon repo is guarded accordingly. The uptime watch that lived here now runs
only in the public site's repository.
