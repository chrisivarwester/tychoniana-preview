The register × life-stage grid

Each writing register (row) crossed with each period of the life (column). A populated cell carries the characterised hand-variant for that combination, graded A–D — select it to read the feature model. An empty cell means no hand-variant has been characterised there: a genuine coverage gap, not an omission.
